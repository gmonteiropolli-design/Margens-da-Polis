# Margens da Polis

Publicação independente de política, história, geografia, sociedade e desenvolvimento.

## Publicar artigos sem editar código

1. Aceda a [Pages CMS](https://app.pagescms.org/) e entre com a sua conta GitHub.
2. Autorize a aplicação Pages CMS a aceder ao repositório **gmonteiropolli-design/Margens-da-Polis**.
3. Abra o repositório. A configuração editorial está em `.pages.yml`.
4. Entre em **Artigos** para criar, editar ou publicar textos.
5. Preencha título, data, secção, autor, resumo, imagem e texto. Guarde as alterações.

Os artigos são guardados em `_posts` e o GitHub Pages reconstrói o site automaticamente após cada publicação.

## Publicação do site

No GitHub, abra **Settings → Pages** e, em **Build and deployment → Source**, escolha **GitHub Actions**. Depois, consulte o separador **Actions** para acompanhar a primeira publicação.

Endereço previsto: https://gmonteiropolli-design.github.io/Margens-da-Polis/

## Estrutura

- `index.html` — página inicial
- `sobre.md` — página Sobre
- `_layouts/` — modelos de páginas e artigos
- `_posts/` — artigos publicados
- `.pages.yml` — campos de edição no Pages CMS
- `assets/css/style.css` — identidade visual
- `.github/workflows/pages.yml` — publicação automática

Os textos apresentados no site devem ser da autoria do editor ou estar devidamente atribuídos.
